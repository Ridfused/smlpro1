      What to do

        How it works

        A statistical model reads the text. Hand-written rules catch modern Indian scams that the 2011 training data never saw.

        1 · Clean

        Unicode NFKC, HTML entities decoded, spaces collapsed. Digits, £, $ and ₹ are kept as strong signals.

        2 · TF-IDF

        Word 1–2-grams plus character 2–5-grams, so “txt”/“text” and misspellings share features, and Devanagari works.

        3 · Linear SVM

        One weight per feature, balanced class weights for the 12% spam minority, C = 0.3 from a 24-setting grid search.

        4 · Calibrate

        Platt (sigmoid) scaling on out-of-fold scores turns the SVM margin into a probability.

        5 · Rules + links

        KYC, OTP, UPI-PIN, prize, delivery, job and investment patterns in English, Hinglish and Hindi; links checked as text.

        Leakage control: the split is made before any fitting. Translations of one SMS, MinHash near-duplicates and messages sharing a phone number are kept in the same group (5,113 groups; 0 cross train/test). The 4,115-message test set is frozen and used once.

        Limitations

        • The training SMS are from 2011 (UK and Singapore), so modern Indian scams are under-represented. The rules help, but they don't fix this.
        • The Hindi data is machine-translated, not real Hindi or Hinglish SMS.
        • The probability reflects the training data, not the real-world chance that a message is a scam.
        • The rule-based scam types are not validated on labelled data.

        Next steps

        • Collect real, consented Indian SMS (English, Hindi, Hinglish), including genuine bank alerts as hard negatives.
        • Fine-tune MuRIL or XLM-R and compare them on the same frozen split.
        • Train a supervised scam-category classifier.

        About

        Statistical Machine Learning project: SMS Spam & Scam Detection. Data: UCI SMS Spam Collection (Almeida et al., 2011) and its public French, German and Hindi machine translations. Built with scikit-learn and Streamlit.
